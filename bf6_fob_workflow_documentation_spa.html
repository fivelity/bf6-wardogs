⚠️ CRITICAL SDK INTEGRATION MANDATE: Non-Barrel Imports

The community library bf6-portal-utils does not provide a barrel export file. Every utility module must be imported strictly from its explicit direct file path. Additionally, `ts-bf6-portal` bundler only accepts relative import paths. each helper contains its own dedicated README.md detailing critical usage insights.

// Correct Relative Direct Path Imports

import { Logger } from "../../node_modules/bf6-portal-utils/Logger/index.ts";

🛡️ Anti-Cheat & Server Rules

  • 1. Hard Radius Limit Check (Max 7.0m) Server rejects placement requests if mod.VectorDistance(player, target) > 7.0 regardless of client UI claims.
  • 2. Authoritative Surface Raycasting Terrain raycasts are computed strictly on the game server to prevent floating FOB exploits.
  • 3. Automatic Garbage Collection Interrupted state triggers automatically call mod.UnspawnObject(hologramId) to prevent lingering ghost meshes.
